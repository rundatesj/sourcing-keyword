# 소싱 키워드 조회

기존 스마트스토어 카테고리 코드 조회 도구를 복사해 만든 별도 공개 프로젝트입니다.

현재 버전은 카테고리 검색과 코드 복사를 제공합니다. 다음 단계에서 네이버 데이터랩 인기검색어 TOP100 조회, 키워드 작업칸, 전체 복사 기능을 추가합니다.

## 공개 배포

정적 프런트엔드는 GitHub Pages에 배포합니다. 인기검색어 요청은 브라우저에서 직접 네이버로 보내지 않고 별도의 Cloudflare Worker를 사용합니다.

## 데이터 기준

- 카테고리 파일 기준일: 2026-08-04
- 카테고리 수: 4,999개

## 주의

네이버 데이터랩의 인기검색어 내부 요청은 공식 공개 API가 아닙니다. 실제 Worker 호출 검증이 끝나기 전에는 샘플 데이터를 실제 데이터처럼 표시하지 않습니다.
